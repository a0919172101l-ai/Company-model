# Lyla Company Knowledge Base

- `data/company_data.json`: summarized knowledge records for the Lyla NLP app.
- `Lyla_Company_Summary_ZH.md`: readable Chinese summary and data limitations.

## Install
Copy `data/company_data.json` into the `data/` folder of your Lyla Streamlit repository.
Keep the app's expected path: `data/company_data.json`.

The JSON keys are compatible with the Lyla app: `title`, `category`, `content`, and `source`.

Important: This data is based on the team's PBL proposal. Candidate services, preliminary estimates, research claims requiring verification, and missing information are explicitly labelled. It must not be presented as confirmed operating-company facts.
